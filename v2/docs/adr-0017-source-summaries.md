# ADR-0017: источники выбранного выпуска или периода

Принято владельцем 2026-09-09 после обнаружения трёх одинаковых подписей
AI Agents Directory в блоке «Источники выпуска».

Причины: API группировал по полному source_name, включавшему заголовок ежедневного
дайджеста; браузер скрывал заголовок, не объединяя строки. Независимая загрузка
футера всегда запрашивала 30 дней и могла не соответствовать выбранному выпуску.

Решение:

- API объединяет известные варианты канала по стабильному ключу до сортировки.
  У AI Agents Directory один ключ для всех daily briefs. Другие неизвестные
  ленты сохраняют собственные имена; совпадение домена не является основанием
  для объединения. Каналы поиска разных периметров различаются.
- Имена для отображения формирует API. Фронт больше не сокращает их независимо.
  Количество — число опубликованных включений материалов за выбранное окно.
  Ограничение в 12 строк и число остальных применяются после объединения.
- `/api/sources?period=day&date=YYYY-MM-DD` выбирает точный выпуск, включая архив
  вне 30 дней. Дата с периодом 7d/30d/yesterday отвергается как неоднозначная.
  Выпуск без материалов или отсутствующая дата возвращают пустой список.
- Для 7/30 дней сохраняются те же окна, что у материалов и статистики.
  Поиск, рубрики и периметр не меняют сводку всего выпуска/периода.
- Заголовок называет дату выпуска либо 7/30 дней. Данные источников загружаются
  параллельно новостям и не блокируют их. Результат применяется только к тому
  поколению запроса, которое успешно показало новости. Отказ обозначается
  явно; чужой период не выдаётся за текущий. Запрос ограничен 2500 мс.

Проверки: объединение/сортировка, сохранение отдельных лент, дата старого выпуска,
пустые даты, границы 7/30 дней, API-валидация, смена периода, запоздавший ответ,
ошибка вторичного запроса, независимая загрузка архива. Три обязательных гейта,
браузерная проверка и ревью второго агента перед выкатом API → фронт.
Миграции БД и изменение данных выпусков не требуются.
