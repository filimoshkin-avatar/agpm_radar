## Настоящий браузер и модель

Проверено на публичном сайте через обычную форму диалога:

1. Вопрос об Atlassian и Salesforce — `radar`, история 0, восемь свидетельств.
2. «Сравни их подходы к управлению доступом» — `radar`, история 1, выполнено
   contextual query rewriting, затем поиск/генерация/проверка. Ответ ограничен
   имеющимися свидетельствами; полнота сравнения не заявляется.
3. После reload: вопрос о положениях автономии в статьях и каноне — `radar_canon`,
   история 2, канонические источники действительно попали в пакет.
4. «Теперь только статьи: какие риски они описывают?» — `radar`, история 3,
   канона в пакете нет.
5. После кнопки нового диалога — `radar`, история 0, прежний scopeRequest отсутствует.
6. Дополнительный публичный JSON-запрос «Какие риски автономии агентов описаны
   во всех документах базы знаний?» — `all`, ответ получен, три канонические цитаты
   среди восьми свидетельств.

Все 26 уникальных claimId из ответов в режиме radar проверены READ ONLY запросом:
26 из 26 имеют путь к выпуску через `agent.statement_trail`. Ошибок JavaScript нет.

Network.getResponseBody. Финальный стенд читает результат из реально сохранённого
