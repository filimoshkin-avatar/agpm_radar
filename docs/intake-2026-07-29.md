## Ключевые требования из handoff

- Сайт: `https://radar.aipractice.space/`.
- Название: «Радар агентного проектного управления».
- Тип продукта: рабочий аналитический радар AgPM, а не маркетинговый лендинг.
- Главная логика: три периметра материалов — близкий, средний, дальний.
- В интерфейсе нужны: сводка выпуска, фильтры, рубрикатор, карточки материалов с кратким пересказом и выводом для AgPM, динамика трендов, хронология выпусков.
- Фильтра источников на фронте нет: источники управляются на бэкенде.
- Дизайн нужно воспроизвести в целевом стеке; файлы `.dc.html` — high-fidelity референсы, не production-код для прямого копирования.
- Рекомендуемый стек по handoff: Next.js/SSR с ежедневной регенерацией.

## Бэкенд-контракт

Ожидаемые сущности:

- `material`: заголовок, URL, источник, дата, периметр, рубрики, краткая суть, вывод для AgPM, verdict, governance-флаг, признак ключевого материала.
- `daily report`: дата, brief, ключевые материалы, статистика дня.
- `stats`: просмотрено, включено, отсечено, дальний/средний/близкий, core/adjacent.
- `time series`: дневная динамика по периметрам.
- `rubrics`: рубрики, счётчики, тренд.
- `sources`: источники, собрано, включено.
- `theses`: тезисы дня.

Рекомендуемые endpoints:

- `GET /api/issue/latest`
- `GET /api/stats?period=day|7d|30d`
- `GET /api/materials?period=&perimeter=&rubric=&verdict=&q=`
- `GET /api/timeseries?days=30`
- `GET /api/rubrics?days=30`
- `GET /api/sources?days=30`
- `GET /api/issues?limit=5`
- `GET /api/issue/{date}`
