# Редизайн V3 — точка входа

Читать первым. Здесь только то, что нужно, чтобы начать; подробности — по ссылкам.

## Задача

Перенести макет `design/v3/Радар AgPM v3.dc.html` во фронт `v2/apps/web`,
сохранив преемственность данных: те же эндпоинты `/api/*` и `/kb/*`, те же
режимы («Радар», «Газета», «Агент»), те же вкладки.

## Что уже лежит и проверено

| | |
|---|---|
| Макет (канон) | `design/v3/handoff/Радар AgPM v3.dc.html` + `support.js` рядом |
| Комплект дизайнера | `design/v3/handoff/` — система, анимации, виджеты, 5 скриншотов v3, `github.md`, шрифты с OFL |
| Производная | `design/v3/artifact-unpacked/` — тот же макет офлайн, разметка нормализована браузером, **сверяться не по ней** |
| Дизайн-система | `design/DESIGN-SYSTEM.md` — характер, шрифты, палитра, компоненты, анти-правила |
| Правила проекта | `CLAUDE.md` в корне |
| Прежний комплект | `design/agent-mode/` (23.08), `work/design_handoff_radar_agpm/` (29.07) — для сравнения |

Формат `.dc.html`: разметка в `<x-dc>`, поведение и мок-данные в
`<script data-dc-script>`. Это **дизайн-референс, а не production-код**:
переносится вид и поведение, а не файлы прототипа.

`handoff/github.md` — карта «экран → файлы репозитория»; начинать перенос
раздела стоит с неё. `handoff/radar_widgets_export/README-widgets.md` описывает
грабли анимаций: `transform-origin` в пикселях, `transform-box`, синхронизация
`animation-delay`.

## Что переносить нельзя

Три скрипта в `design/v3/` — среда выполнения прототипа. Фронт V2 остаётся
**без зависимостей**: один `app.mjs`, один `styles.css`, без сборки. Единственное
исключение — вендоренный Cytoscape, и под него написан ADR-0009.

Шрифтов в макете 23 начертания, во фронте сейчас два (Golos Text, PT Mono).
Либо добавлять в артефакт релиза, либо сводить к имеющимся. CSP на
`radar.agpm.space` разрешает `fonts.googleapis.com` и `fonts.gstatic.com`.

## Долг по анти-правилам на 2026-08-25

Текущий прод нарушает дизайн-систему в двенадцати местах. Замерено, не на глаз:

```
градиенты        6   linear-gradient × 4, radial-gradient × 2   styles.css
scrollIntoView   6   app.mjs
шрифты вне списка 0  ✓ чисто
```

Плюс десять типографских стрелок и галочек (← → ↗ ↘ ✓ ✕) — формально не эмодзи,
решение владельца не запрошено.

Долг **зафиксирован числом** и проверяется гейтом
(`v2/tools/check_design_rules.py`, шаг «design-system debt»). Убирая нарушение,
опускай число там же — иначе гейт покраснеет и напомнит.

Палитра в проверку пока не входит: 42 из 93 hex-значений в `styles.css` вне
токенов, и это старая схема, которую редизайн заменяет целиком. Такое число
ничему не учит, пока не станет малым — добавить, когда редизайн сядет.

## Перед первым коммитом

Три гейта, по коду возврата. И **два кэш-токена**: редизайн тронет и `app.mjs`,
и `styles.css` — поднимать надо оба, иначе изменение не доедет до вернувшегося
читателя.
