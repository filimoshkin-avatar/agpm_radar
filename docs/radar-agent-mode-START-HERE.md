# СТАРТ: режим «Агент» на radar.agpm.space

Точка входа новой сессии. Читать первым. Дата: 2026-08-24.

## 1. Цель

На **https://radar.agpm.space/** есть переключатель режимов. Сегодня в нём два
положения — «Радар» и «Газета». Нужно третье: **«Агент»**, и за ним — полнофункциональная
проверенная база знаний по агентному управлению: доказательный поиск, диалог с
раскрытием цепочки до первоисточника, Обсерватория, карточки понятий и wiki.

Продукт считается сделанным, когда выполняется критерий владельца — **двусторонняя
трассируемость**: от вопроса к выводу, утверждению, точному фрагменту и первоисточнику
— и обратно, от нового материала выпуска к утверждениям, понятиям, связям и
предложению обновить wiki.

## 3. Архитектура: это две разные системы

Главное, чего не видно из адреса: за `radar.agpm.space` стоят **два хранилища**.

```
                         Caddy на Local Ru (194.87.143.141)
                                     │
        ┌────────────────────────────┼──────────────────────────────┐
        │                            │                              │
   /  и /assets                  /api/*  /gazettes/*             /po/*
  статика SPA                  127.0.0.1:8765                127.0.0.1:19702
        │                            │                              │
  /srv/radar-v2.../apps/web    V2 public API                  редактор KX
                               (схема 1, свои                 (схема 22,
                                release id)                    знания)
```

- **V2** — лента выпусков и газета. Своя база, схема 1, свои релизы `app_release_*`.
  Код в `apps/`, `packages/` этого репозитория.
- **KX** — база знаний: документы, цитаты, утверждения, темы, статусы. Схема **22**.
  Код в `kx/`. **Публичного HTTP-доступа у KX нет вообще** (ADR-0005 §16) — наружу
  торчит только редактор владельца на `/po/`.

**Следствие для задачи:** режим «Агент» требует нового read-only сервиса поверх KX и
нового маршрута в Caddy. Оба — из списка «нельзя без подтверждения» (§9).

Фронтенд простой, без фреймворка: `apps/web/index.html` (183 строки),
`apps/web/app.mjs` (1 369), `apps/web/styles.css` (1 174).

Переключатель уже есть — `apps/web/index.html:176-179`:

Нужна третья кнопка `data-view-mode="agent"` и вид под неё. Обработчик режимов — в

Для проектирования вида «Агент» уместен навык **Claude Design**: он даёт холст с
артбордами, который владелец правит руками, а не в коде. Четыре уровня раскрытия из
UC-02 (краткий ответ → аналитический → доказательства → исходные материалы → граф) —
это как раз то, что стоит нарисовать до реализации.

## 6. Двадцать решений владельца

Пятнадцать об устройстве базы (§14 документа скелета) и пять о плане. Кратко:

**Устройство.** Пересказ несколькими изданиями — подтверждение, но с первоисточником и
пометкой. Единица базы — и одиночное утверждение (статус «наблюдаемый сигнал»), и
слитое подтверждённое; на входе фильтр: **о классе — в базу, событие рынка — в
Обсерваторию, вендорский перечень — вон**. Утверждение без места в скелете копится в
«карте пробелов». «Подтверждает» — всё релевантное, но видно **чем**. Срок
актуальности — правило по типу материала, по истечении очередь на пересмотр. Четыре
типа связей. Жанр — свойство раздела, страницы не режем.

**Власть.** За владельцем — **канон, статус и всё, что публикуется её голосом**.
Привязку к темам, связывание и публикацию сигналов машина делает без визы. Статус
поднимается по предложению машины с её визой.

**Наружу.** Ответ агента — свободный текст с пометкой «машинный ответ, не редакция
базы» и цитатами под ним. **Чат — не публикация**: вопросы и ответы хранятся для
анализа, процедуры публичного отзыва не нужно, постоянных адресов у ответов нет.
Лицензия открытая с атрибуцией. Подпись двойная: авторские страницы — именем
владельца, производное — «AgPM Radar, машинная сборка».

**Продукт.** Читатель на запуске — **PMO / AgPMO**. Запуск с агентом. Охват — правило:
материалы выпусков плюс канон AgPM, набор растёт. Обсерватория — **срез по классам
событий**, не лента. Оценки идей — четыре оси, машина, с пометкой, без сводного балла.
Инкремент раздельный: сигналы видны сразу в Обсерватории, в предметные разделы —
только прошедшее синтез и визу.

## 9. Что нельзя без отдельного подтверждения владельца

- применение миграции к production и переключение `/opt/radar-kx/current`;
- **любой новый systemd-юнит** (read-only сервис KX — это новый юнит);
- **любые изменения Caddy** (маршрут режима «Агент» — это изменение Caddy);
- любая запись в production-базы;
- расширение списка моделей на Local Ru за пределы `zai/glm-5.2` и `minimax/MiniMax-M3` (P9).

## 11. Грабли, которые дорого выяснять заново

- **Миграция убивает идущий пакетный прогон.** Порядок: остановить оркестратор →
  бэкап → миграция → деплой → перезапуск.
- **Проверять код возврата, а не хвост вывода.** `| tail -4` съедает статус.
- **`kxrun` не читает ключи моделей.** Извлечение через него однажды записало 1 053
  упавших прогона за полторы минуты.
- **`uv export` цветной** — гейт падает без `NO_COLOR=1`.
- **`jsonb_array_elements` с `ORDER BY … LIMIT 1`** режет **после** развёртки: считать
  надо через подзапрос, иначе получите одну строку вместо двухсот.
- **58 «понятий» в хранилище — это страницы wiki**, а не понятия. Понятия — 229
  элементов скелета.
- **`v2/scripts/run_stage15_daily.sh` изменён другой сессией** и не закоммичен. Не
  трогать. Вопреки прежней записи, v2-гейт от него **не краснеет** — проверено
  2026-08-23, все три гейта зелёные.
- Второй дефект цитат — следы разбора PDF (726 с переводом строки, 443 со склеенными
  словами). Кодом не чинится, только перепарсингом, а тот родит новые идентификаторы.
  **Не чинить**, это записанный предел качества.
