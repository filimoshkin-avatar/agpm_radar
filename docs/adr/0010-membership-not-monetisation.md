# ADR-0010: Подписка — членство, не монетизация

Дата: 2026-08-25 · Статус: принято (владелец) · Смена решения: ADR-нет, список
гейтирования в `agent_api.py` (2026-08-24 «граница продукта» отменяется)

## Контекст

Проект бесплатный и некоммерческий. Ключ подписки существует не для сбора денег,
а для включения в сообщество: человек с ключом получает больше возможностей в
работе с системой — и в ответ участвует в развитии канона. Это меняет ответ на
вопрос «что можно огораживать»: у нас нет платежной границы, значит нет и
предмета защиты. Дважды за сутки список гейтирования менялся туда-обратно
(`/graph` свободен → гейтен → свободен); этот ADR закрывает качели.

## Решение

1. **Чтение, которое делает сам диалог, свободно у источника.** Разговор может
   раскрыть всё, что он показывает: окрестность известного узла (`/graph`),
   утверждение с его связями (`/statement`). Ограждать один из двух путей,
   которыми чат ходит по базе, бессмысленно — измерение 2026-08-24 показало,
   что при гейтеном `/graph` путь `/statement/<id>` продолжал раздавать те же
   тексты с соседями: забор с открытой калиткой — шум, а не стена.
2. **Ключ открывает аппарат, а не данные:** полки (поиск, Обсерватория,
   Противоречия, Понятия, Wiki, Пробелы), более широкое окно вопросов
   (30/5 мин), позже — ленты (RSS на узлы). Разница члена — в том, что он
   **может делать**, и в том, что он должен: участвовать в развитии канона.
3. **Ничто здесь — не платёжная граница.** Скрипту, желающему выкачать тексты,
   тексты не принадлежат; сообщество существует не для них.

## Участие члена в каноне (направление, следующие приращения)

Машина предлагает — владелец решает; члены сообщества предлагают так же.
Кандидатные механизмы (каждый питает существующие очереди `/po/`):

- предложить правку Wiki-страницы (очередь wiki уже ждёт решений);
- предложить повышение статуса утверждения (очередь из 611 кандидатов есть);
- назвать тему для карты пробелов (таблица `claim_gaps` готова);
- указать на противоречие, достойное разбора (вкладка «Противоречия»).

Открытие записей от читателей — отдельное приращение с собственной миграцией
и гейтом по ключу; до него членство остаётся «больше apparatus + голос в
очередях через владельца».

## Последствия

- `GATED_PATHS`: `/search`, `/topics*`, `/observatory`, `/entities`,
  `/contradictions`, `/gaps`, `/pages*` — и ничего из путей диалога.
- Бесплатный читатель: Радар, Газета, диалог с агентом целиком (включая
  блуждание графом карточками в чате — решение владельца 2026-08-24
  «переходы из чата работают в чате» остаётся в силе).
- Член: всё выше + полки + широкое окно + будущие ленты + будущие очереди
  предложений.
- Список гейтирования меняется только вместе со ссылкой на этот ADR.
