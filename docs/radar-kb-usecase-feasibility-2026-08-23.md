# Юзкейсы против того, что есть в хранилище

Замер 2026-08-23, после применения миграции 022. Проверялось одно: на каких
юзкейсах из документа владельца сегодня хватает данных, а на каких нет — по базе,
а не по рассуждению.

## 1. Чего в хранилище нет вообще

**Сущностей ноль.** Таблица `kx.entities` пуста, и ни у одного из 7 929 утверждений
периметра нет `subject_entity_id`. Организаций, авторов, платформ, стандартов и
отраслей в базе не существует.

Это подрезает сразу несколько юзкейсов:

| Юзкейс | Что требует | Состояние |
|---|---|---|
| UC-04 карточка понятия | связанные сущности, кейсы, стандарты | нет сущностей |
| UC-05 граф, режимы «организационный», «по рискам и контролям», «по практикам» | 13 типов сущностей | нет ни одного |
| UC-07 динамика темы | «основные организации и авторы» | нет |
| UC-13 подбор кейсов | фильтры по отрасли, размеру организации, платформе | нет |

**Граф есть, но он не тот.** 11 466 узлов — это происхождение, а не знание:

```
claim          10 299
concept_claim     314
version           285
document          285
source_family     155
idea               70
concept            58
```

Ни сущностей, ни тем скелета в графе нет. Из шести режимов UC-05 достижимы два —
доказательный и по источникам.

**Даты публикации не разобраны.** У материалов есть `published_raw` — текст как
пришёл, у 786 из 1 102. Разобранной даты публикации в схеме нет ни на документе, ни
на версии; есть только `fetched_at`, то есть когда радар материал увидел.

## 2. UC-07 «динамика за 12 месяцев» — данных нет

Периметр покрывает **2,5 месяца**:

| Месяц | Документов |
|---|---:|
| 2026-06 | 76 |
| 2026-07 | 54 |
| 2026-08 | 147 |

Первый материал — 2026-06-07, последний — 2026-08-21. Запрос «как менялось внимание
за последние 12 месяцев» на этих данных не отвечается никакой техникой. То же
ограничивает UC-15 (подписка на изменение динамики) и часть UC-08 («устойчивость во
времени», «быстрорастущие темы»).

Это не дефект и не повод расширять корпус: радар просто младше, чем горизонт вопроса.
Юзкейс станет исполним сам, когда наберётся история.

## 3. UC-03 «цифры с контекстом» — сырьё есть, структуры нет

Из 7 929 утверждений периметра:

| | |
|---|---:|
| содержат хоть одну цифру | **3 591** |
| содержат процент | 904 |
| содержат деньги | 322 |

То есть материал для таблицы показателей есть — порядка тысячи утверждений с
процентами и суммами. Чего нет: **структуры**. `claims` хранит предикат, объект и
нормализованный текст; поля «значение», «единица измерения», «выборка», «период»,
«ограничения исследования» в схеме отсутствуют. Требование юзкейса «значение без
объекта измерения, выборки и периода не считается полноценным фактом» сегодня
проверить нечем.

## 4. Обрывки: два разных дефекта, и первый втрое меньше, чем кажется

Первый счёт дал 29,4 % цитат, не кончающихся знаком конца предложения, и я едва не
записал это как «треть доказательной базы порвана». Разложение по форме показывает
другое:

| Форма цитаты | Штук | % |
|---|---:|---:|
| целое предложение | 5 619 | 70,9 |
| без конечной точки — заголовок, пункт списка, ячейка таблицы | 1 628 | 20,5 |
| вырвано из середины (начинается со строчной буквы) | 602 | 7,6 |
| кончается двоеточием — вводная перед списком | 47 | 0,6 |
| оборвано на запятой или точке с запятой | 33 | 0,4 |

**Реально порвано границей — 682 цитаты, 8,6 %.** Остальные 20,5 % — именные группы и
заголовки вроде «Deloitte's latest survey of more than 500 U.S. business and IT
leaders»: не предложение, но как выдержка читается.

И отдельно нашёлся **второй дефект с другой причиной**: 726 цитат (9,2 %) содержат
перевод строки, 443 (5,6 %) — склеенные слова вида `consistentlydegradesperforma`,
36 — переносы с дефисом. Это следы разбора PDF, а не выбора границ:

> incorporating human analyst rec-
> ommendations into the AI ensemble consistentlydegradesperforma

Разница практическая. **Границы спана чинятся промптом извлечения** — дёшево и без
последствий для идентификаторов. **Качество текста версии чинится только
перепарсингом**, а перепарсинг родит новые версии и новые `claim_id`, то есть осиротит
всё, что к ним привязано. Необратимость сидит во втором дефекте, а не в первом.

## 5. Что из юзкейсов достижимо на том, что есть

| Юзкейс | Достижимость |
|---|---|
| UC-01 доказательный поиск | **да** — оба поиска живы, 13 876 цитат с точными спанами; «почему найдено» требует дописать объяснение |
| UC-02 диалог с раскрытием | **да по цепочке**, механизм проверки по спанам построен; расходится с решением 5 по контракту генерации |
| UC-10 карта пробелов | **да** — таблица `claim_gaps` из миграции 022 |

| UC-09 предложения для wiki | частично: слой идей есть, покрывает 2 % утверждений |
| UC-03 цифры | сырьё есть, структуры нет |
| UC-04, UC-05, UC-13 | нет: нет сущностей |
