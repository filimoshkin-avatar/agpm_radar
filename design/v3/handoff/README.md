# Handoff-пакет: Радар AgPM v3

Пакет для Claude Code / разработчика. Порядок чтения:

1. **DESIGN-SYSTEM-v3.md** — правила дизайн-системы «Терминал на бумаге»:
   шрифты, цветовые токены, рецепты компонентов, паттерны, анти-правила.
2. **Радар AgPM v3.dc.html** + **support.js** — живой эталон (откройте html
   в браузере рядом с support.js). Три раздела: Радар / Агент / Газета,
   вся интерактивность рабочая.
3. **screenshots/v3-\*.png** — ключевые состояния:
   радар (выпуск), радар (30 дней, кольцо), агент-приветствие,
   агент-ответ с доказательствами, газета.
4. **radar_widgets_export/** — самодостаточные анимированные виджеты
   (сонар / доли / кольцо) + README о подводных камнях
   (transform-origin в px, transform-box, синхронизация animation-delay).
5. **github.md** — связь с репозиторием agpm_radar: карта «экран → файлы»,
   история синхронизаций.
6. **favicon.svg / favicon-animated.svg** — иконки бренда.
7. **fonts/**, старые скриншоты без префикса v3 — материалы первой версии
   радара (для контекста преемственности).

Репозиторий продакшена: https://github.com/filimoshkin-avatar/agpm_radar
(v2/apps/web — текущий фронтенд, данные и контракты брать оттуда).
