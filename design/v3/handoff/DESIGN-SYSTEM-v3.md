# Радар AgPM v3 — дизайн-система «Терминал на бумаге»

Инструкция для Claude Code (или любого разработчика/агента): как строить новые
интерфейсы в едином стиле с макетом `Радар AgPM v3.dc.html`.
Эталон истины — сам макет; этот файл — краткая выжимка правил.

## 1. Характер

Bloomberg Terminal, перенесённый на бумагу: плотные данные, моноширинная
разметка, тонкие линейки, минимум декора. Светлый фон, ни одного градиента,
ни glassmorphism, ни цветных заливок-«героев». Скругления малые (4–10px),
тени — только у плавающих слоёв (поповеры, пилюли, голосовой оверлей).

## 2. Шрифты

- **Golos Text** (400/500/600/700) — весь UI-текст. Заголовки 600, letter-spacing −0.01em.
- **PT Mono** — ВСЕ данные и служебные подписи: числа, даты, счётчики, статусы,
  метки секций (uppercase, letter-spacing .05–.09em, 9.5–11px), тикер, кнопки-действия
  в карточках (ДОКАЗАТЕЛЬСТВА · 2).
- Газета (только раздел «Газета»): Playfair Display + Georgia + Roboto Condensed.

Подключение:
https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&family=PT+Mono&display=swap

## 3. Цвета (токены)

Фоны:
- страница `#f7f5ef`; карточки/панели `#fdfcf9`; чистые поля ввода `#fff`
- подложка второго уровня (фильтры, композер) `#f9f7f0`; рейка агента `#f6f3ea`
- графит (тикер, футер, тёмные кнопки, пузырь вопроса): `#16212c`, кнопки `#1f242a`

Линии: основной бордер `#ddd8ca` / `#d9d4c5`; внутренние линейки `#e6e2d4`, `#eeeadd`.

Текст: основной `#1f242a`; вторичный `#4a525a` / `#5b636b`; приглушённый `#8a8677`;
подписи-мета `#a29d8d`; на графите: `#f2efe6`, вторичный `#97a1ab` / `#8a94a0`.

Смысловые:
- **Янтарь (акцент бренда)** `#a96b12`, светлый `#d9a253` — активный сигнал, «сегодня»,
  машинный ответ, микрофон, номер тезиса. Один акцент на блок.
- Периметры: близкий `#2b4a75` · средний `#1e6e62` · дальний `#6b6880`
  (на графите: `#8fb0dc` / `#6fc0b2` / `#a9a6c4`)
- ОК-статус `#4f9e6e` (`#7ec699` на графите); опасность/стоп `#b5432e`
- Полупрозрачные подложки — только rgba от этих же цветов (напр. rgba(43,74,117,.06))

## 4. Компоненты (копируй разметку из макета)

- **Сегмент-переключатель**: рамка 1px `#d9d4c5`, radius 6, PT Mono 11px,
  активный сегмент — заливка `#1f242a` + текст `#f7f5ef`, разделители border-left.
- **Чип-фильтр**: h26–27, radius 5–6, белый фон, цветная точка 6px слева;
  активный — графитовая заливка. Клик по активному = сброс.
- **Карточка**: `#fdfcf9`/`#fff`, бордер 1px, radius 6–8; заголовочная строка
  с подписью PT Mono справа; внутренние разделители `#eeeadd`.
  Карточка «машинного ответа» — с левой янтарной кромкой 2px.
- **Кнопки**: primary — графит `#1f242a`, radius 6; secondary — белая с бордером;
  запрещённая/тарифная — пунктирный бордер + замок; стоп — текст `#b5432e`.
- **Тултип**: графит `#16212c`, radius 6, 11.5px, тень 0 10px 26px rgba(0,0,0,.25).
- **Поповер**: белый, бордер `#d9d4c5`, radius 8, тень 0 16px 40px rgba(31,36,41,.16),
  mono-шапка uppercase.
- **Замок подписки**: контурный lock `#c0bbaa` + тултип
  «Доступно по подписке экспертного сообщества AgPM».
- **Пилюли навигации**: radius 99, графит (или белая с бордером), fixed, тень.
- **Данные**: тренд-бары высотой 7–8px на подложке `#f0ece0`; стеки Б/С/Д цветами
  периметров; heatmap — rgba(43,74,117, α), «сегодня» янтарём; выходные opacity .45.

## 5. Паттерны поведения

- Анимации: вращение луча (linear, 4–8s), пульс блипов, ступенчатое появление
  ответа (agIn, шаг 160ms), вспышка-подсветка (agFlash). ВСЁ гасится через
  `@media (prefers-reduced-motion: reduce)` — помечай анимируемое `data-anim`.
- Переключение периода: skeleton-приглушение opacity .3 → данные меняются.
- Честность интерфейса: машинный ответ всегда помечен; «показано N из M»;
  честный отказ «в базе нет подтверждений» — фича, не ошибка.
- Цепочка доверия: ОТВЕТ → УТВЕРЖДЕНИЕ → ЦИТАТА → ПЕРВОИСТОЧНИК (PT Mono).
- Числа согласованы между всеми блоками одного экрана (37 = 9+14+14 и т.п.).

## 6. Раскладка

- Контент max-width 1440px, паддинги 20–24px; сетки CSS grid с gap 14px.
- Адаптив: auto-fit/minmax где возможно; остальное — media-правила ≤940px
  (hero и агент в одну колонку, рейка горизонтальная) и ≤720px (газета).
- Шапка sticky (z 40); рейка агента sticky top 60, схлопывается до 64px
  (иконки, подписи скрыты через `[data-lbl]`); композер sticky bottom.
- Тап-цели на мобильном ≥ 40px.

## 7. Анти-правила

Нельзя: градиенты, эмодзи, цветные левые бордеры-«акценты» вне карточки ответа,
Inter/Roboto/Arial, тени на статичных карточках, новые цвета вне палитры
(если не хватает — oklch-производная от существующих), scrollIntoView.

   (сонар/доли/кольцо) + README о SMIL, transform-origin, animation-delay.
3. `github.md` — карта «экран → файлы репозитория» и история синхронизаций.
4. Репозиторий: https://github.com/filimoshkin-avatar/agpm_radar (v2/apps/web —
   текущий продакшен, с которым нужно сохранять преемственность данных).
