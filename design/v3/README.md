# Макет «Радар AgPM v3»

## Что здесь канон

**`handoff/` — комплект дизайнера, эталон истины.** Открывать
`handoff/Радар AgPM v3.dc.html`: рядом лежит `support.js`, на который он
ссылается, шрифты подтягиваются с Google Fonts (офлайн-копии — в
`handoff/fonts/`). Три раздела, вся интерактивность рабочая.

**`artifact-unpacked/` — производная, не канон.** Тот же макет, распакованный
из артефакта `claude.ai/code/artifact/29cd994d-5983-45c2-bbef-50bf3749a166`
(2026-08-25): ресурсы разложены по UUID, поэтому открывается офлайн без сети.
Прошёл через упаковщик и браузер, отчего разметка нормализована — тела
расходятся с исходником на 1 400 символов из 110 000 (0,8 %): добавленные
`<tbody>`, переписанные атрибуты. **Сверяться следует с `handoff/`**; эта копия
удобна, когда нет интернета, и не более.

Формат `.dc.html`: разметка в `<x-dc>`, поведение и мок-данные в
`<script data-dc-script>`. Это **дизайн-референс, а не production-код**.

## Что уже решено и не сочиняется заново

Замок на закрытом пункте меню — всплывающая подсказка по наведению, обёрнутая в
`sc-if`:

> **Доступно по подписке экспертного сообщества AgPM**

Шесть вхождений, по числу закрытых пунктов. Согласуется с ADR-0010: подписка —
членство в сообществе, а не монетизация. Слов «оплата», «стоимость», «купить»,
«тариф» в макете нет.

## Чего требует перенос

- **Три скрипта прототипа переносить нельзя.** Фронт V2 остаётся без
  зависимостей: один `app.mjs`, один `styles.css`, без сборки. Единственное
  исключение — вендоренный Cytoscape (ADR-0009). Переносится поведение.
- **Два кэш-токена.** Редизайн тронет и `app.mjs`, и `styles.css`; у каждого свой
  `?v=` в `index.html`, оба отдаются `immutable` на год. Поднимать оба.
- **Долг по анти-правилам** на 2026-08-25: 6 градиентов в `styles.css`,
  6 `scrollIntoView` в `app.mjs`. Редизайн эти файлы перепишет.
